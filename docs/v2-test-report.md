## 发现与修正

1. 新增组件直接在渲染中调用Date.now被React规范检查拒绝；移除渲染时动态时间判断，关键限制保留在领域操作校验中，规范检查通过。
2. 活动编辑必须保留requiresReview和eligibilityText；补齐字段并用本地时间格式化代替UTC字符串截断，避免编辑丢条件及时区漂移。
3. 首轮浏览器测试全部连接失败，定位为服务监听localhost的IPv6地址而测试访问127.0.0.1。统一localhost并增加自动启动服务；随后7场景通过。
4. 数据损坏时原V1逻辑可能删除旧键并重置。改为严格校验、提示错误、保留原数据，单元及浏览器验证通过。
